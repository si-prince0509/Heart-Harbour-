# 💖 Heart Harbour

Heart Harbour is a modern AI chat web application designed with a beautiful
romantic interface and interactive user experience.

## ✨ Features

- 💬 AI-powered chat
- ❤️ Romantic and supportive AI personality
- 🎴 Interactive profile card slider
- 🎨 Modern pink/red UI
- 📱 Responsive design
- ✨ Smooth animations
- ⌨️ Enter-to-send messaging
- ⏳ Typing indicator
- 🔄 Fresh chat session on every run
- 🧭 Separate Home and Chat pages

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Gemini API
